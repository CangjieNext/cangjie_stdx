# cangjie_stdx::logger

## Introduction

The `cangjie_stdx::logger` module provides log printing functions in both text format and JSON format. It offers flexible logging capabilities with support for multiple output formats.

## Features

- **Multiple Formats**: Supports both text and JSON log formats
- **Structured Logging**: Enables structured log output for better parsing and analysis
- **Configurable Output**: Allows customization of log output destinations
- **Rich Metadata**: Includes timestamps, log levels, and other metadata in log entries

## Usage

To use the logger module in your project, add the following dependency to your `cjpm.toml`:

```toml
[dependencies]
stdx = { path = "path/to/stdx" }
```

Then import the logger module:

```cj
import cangjie_stdx::logger
```
